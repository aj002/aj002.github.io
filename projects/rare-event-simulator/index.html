Rare Event Simulator

Imagine trying to measure how often a 1-in-a-million event happens — by just running random trials. You'd need millions of tries and still might get zero hits. This simulator shows a smarter approach: importance sampling steers random paths toward the rare zone, then corrects the bias with math so the answer stays honest. Watch both methods race side by side.

The Smart Strategy — Explained
1 Nudge paths toward the rare zone Instead of hoping a random path stumbles into the tail, we add a small drift (called λ) that gently pushes paths toward the threshold. More paths cross → more data about the rare event.
🎣 Like fishing where the fish are, instead of casting randomly across the ocean.
2 Weigh each path to undo the bias Because we pushed paths, they're no longer "fair" random samples. So we compute a likelihood ratio (weight) for each path — if we pushed it a lot, we down-weight it. The math:
weight = exp(−λ·WT + ½λ²T)
This correction makes the final answer unbiased.
⚖️ Like a survey that over-samples a group, then re-weights to reflect the real population.
3 Average the weighted results Each path that crosses the threshold contributes its weight × 1. Paths that don't cross contribute 0. The weighted average gives us the true rare-event probability — but with far less noise than regular sampling.
📊 Same truth, 10–1000× less noise.

Under the Hood

The Math (optional)

Why regular Monte Carlo struggles with rare events
Regular Monte Carlo estimates P(rare event) by counting how many random trials happen to hit the tail. If the event has probability p, you need roughly 1/p samples just to see it once — and many more for a stable answer.
Relative error ≈ 1 / √(n · p)
For p = 10⁻⁶, you'd need ~10⁸ samples for 1% relative error. That's wasteful.
How importance sampling fixes this
Core idea: sample from a different distribution Q that puts more mass in the rare region, then correct with the likelihood ratio dP/dQ.

In this simulator, we tilt the SDE's drift by a constant λ:
dX = [b(X,t) + λ·σ(X,t)] dt + σ(X,t) dW̃
Under Girsanov's theorem, the likelihood ratio for a Brownian path is:
L = exp(−λ·WT + ½·λ²·T)
The IS estimator is then:
p̂IS = (1/n) Σ 1{XT > threshold} · L
This estimator is unbiased (E[p̂] = p) but has much lower variance when λ is chosen well — typically λ ≈ (threshold − mean) / (σ·T).
Connection to the WSC 2024 paper
This demo uses a constant tilt λ, which works well for simple processes. The paper tackles harder problems — multi-dimensional diffusions where the optimal tilt varies in space and time. It uses deep learning to learn the optimal change of measure, guided by the Hamilton-Jacobi-Bellman PDE.

Think of this simulator as the "level 1" version — it builds the intuition you need before diving into the neural-network approach.
